# CampusKai

CampusKai is a digital campus ecosystem designed to bring structure and connectivity to college life.

The platform aims to provide a centralized system for :

- Student Council
- Clubs and Communities
- Event Management
- Campus Announcements
- Student Profiles

## Vision
To build a structured digital environment where students, clubs, and faculty can collaborate and organize campus activities efficiently.

## Tech Stack (Planned)

Frontend: React  
Backend: Node.js + Express  
Database: MongoDB

## Status
Currently in planning and development phase.
